# audio/freesound

Sounds fetched from [freesound.org](https://freesound.org) by the `freesound_search` and `freesound_download` MCP
tools (`src/net/Freesound.cpp`). Each file has a `.json` beside it with the Freesound sound number, author, licence and
page, which is the record the licence asks a user to be able to find again.

They are the 192 kbps Ogg previews. A Freesound API key can fetch those; the original upload needs an OAuth2 login,
which these tools do not do. For anything that depends on the top of the spectrum, download the original from the
sound's page.

All of those below are [Creative Commons 0](https://creativecommons.org/publicdomain/zero/1.0/), read from the API on
1 November 2026. `examples/drum-machine.ttl` plays them.
