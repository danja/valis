As a system-wide test, with MCP tools, create an interesting set of instruments with effects circuits that will be used in a Halloween-themed track. Something with the feel of a dubstep version of "Bela Lugosi's Dead" with ornamental sounds from old sci fi and horror movies, a hint of Doctor Who. Keep track of any failings, their corrections should be added to TODO.md

These should be saved with the existing examples :

* halloween-drums-low.ttl - kick and any other low percussive sounds, something ominous but danceable
* halloween-drums-high.ttl - hi hats etc, with varied processing
* halloween-bass.ttl - a couple of different types of bass synths, layered
* halloween-organ.ttl - you decide what's appropriate
* halloween-guitar.ttl - echoing twangy realistic sound
* halloween-theremin.ttl - spooky
* halloween-ornaments1.ttl - eery, you decide
* halloween-ornaments2.ttl - disturbing, you decide

Once they are created used reaper-mpc tools to create a 3 minute long song using the instruments above. Make it catchy but haunting. Think of a suitable title.
Save Reaper files in the named dir under  ~/Music/
