# Archived song scripts

These two scripts wrote, rendered and mixed songs before songs were described in Turtle (`val:Song`, see
`docs/songs.md`). They are kept as a record and are not maintained or converted.

- `electro83/track.py`: "Tenement Lights", described in `docs/new-order-track.md`.
- `halloween/song.py`: "Dead at Midnight", described in `docs/halloween-process.md`.

Both import `midiw.py`, which now lives in `scripts/song/` beside `songlib.py`. A new song uses `song.ttl` and
`valis-song`; see the `write-a-song` skill.
