# Case study: TR-909 drum synthesiser

The `examples/909.ttl` circuit models the [Roland TR-909](https://en.wikipedia.org/wiki/Roland_TR-909) drum machine as nine independent voice sub-circuits inside a single Valis circuit. It demonstrates the `val:NoteGate` element, the Envelope gate-override input, and the `val:section` parameter grouping introduced to support multi-instrument circuits.

## Problem: per-note routing

The Valis engine broadcasts a single MIDI state (`gate`, `noteNumber`, `velocity`) to every element in a circuit. In a synthesiser, that is the right design — one note drives the whole circuit. In a drum machine, nine separate instruments must respond to nine different note numbers simultaneously.

The solution is `val:NoteGate`, a source element that filters the global gate by note number:

```turtle
:bdGate a val:NoteGate ; val:note 36 .
```

`NoteGate` has two control outputs:
- `gate` — 1.0 when `args.gate && args.noteNumber == note`, otherwise 0.0
- `velocity` — the velocity at the time the note triggered, held until the next trigger

A control arc connects `NoteGate.gate` to `Envelope.gate`, which is a new optional input port on the existing Envelope element:

```turtle
:aBdGateAmpEnv a val:ControlArc ;
    val:from [ val:node :bdGate   ; val:port "gate" ] ;
    val:to   [ val:node :bdAmpEnv ; val:port "gate" ] .
```

The Envelope gate port has a default of `-1.0`, which acts as a sentinel: `-1` means "use the host MIDI gate" and `0` or `1` means "use this value". Existing circuits that do not connect anything to `gate` continue to work without change.

## General MIDI channel 10 map

| MIDI note | Instrument    | Circuit blocks                                        |
|-----------|---------------|-------------------------------------------------------|
| 36        | Bass Drum     | Oscillator + pitch envelope sweep, saturation, VCA    |
| 37        | Rim Shot      | Noise through highpass filter, short VCA              |
| 38        | Snare Drum    | Oscillator + band-passed noise mixed, VCA             |
| 39        | Hand Clap     | Noise through bandpass filter, VCA                    |
| 41        | Low Tom       | Triangle oscillator, amplitude decay                  |
| 43        | Mid Tom       | Triangle oscillator, amplitude decay                  |
| 50        | High Tom      | Triangle oscillator, amplitude decay                  |
| 42        | Closed HH     | Two square oscillators, highpass, very short decay    |
| 46        | Open HH       | Two square oscillators, highpass, longer decay        |

## Instrument circuit blocks

### Bass Drum

The 909 kick is a triangle oscillator whose pitch falls rapidly from an attack peak (~180 Hz) down to the body frequency (~50 Hz). A fast pitch envelope controls a Scale element, which maps the 0–1 envelope output to the frequency range. The amplitude envelope has a longer decay. A Tanh stage adds the characteristic punch:

```
NoteGate → pitchEnv.gate    → Scale → Oscillator.frequency
NoteGate → ampEnv.gate      → VCA.cv
Oscillator → Tanh → VCA
```

### Snare Drum

Two sources contribute to the snare sound: a triangle oscillator at 180 Hz provides the tonal body, and white noise filtered through a bandpass at ~1 kHz provides the snare rattle. They are mixed in equal proportion:

```
NoteGate → Envelope.gate → VCA.cv
Oscillator ──────────────┐
Noise → StateVariable.bp ┘→ Mixer → VCA
```

### Toms

Low, Mid and High Toms follow a simplified version of the Bass Drum without the pitch envelope: a triangle oscillator at a fixed frequency (100, 150, 220 Hz respectively) through an amplitude-decay VCA. Adding a pitch sweep is straightforward by inserting an Envelope and Scale on the frequency control path.

### Rim Shot

A white noise burst through a OnePole highpass filter at 800 Hz gives the dry, sharp click of the rim shot. The decay is 30 ms.

### Hand Clap

White noise through a StateVariable bandpass at 1.2 kHz with a 100 ms decay. The original circuit layered multiple echoes to simulate the sound of several hands clapping; that layering is not modelled here.

### Hi-Hats

The 909 hi-hat section uses six square-wave oscillators at specific inharmonic ratios to produce a metallic tone. The two most prominent ratios (approximately 1 : 2.08) are modelled here with two square oscillators at 562 Hz and 1170 Hz:

```
NoteGate → Envelope.gate → VCA.cv
Oscillator (562 Hz, sq) ──┐
Oscillator (1170 Hz, sq) ─┘→ Mixer → StateVariable.hp → VCA
```

The highpass cutoff at 5 kHz removes the low partials, leaving the metallic upper register.

Closed and Open hi-hats share the same spectral source but differ in decay time (35 ms vs 400 ms). The original circuit implemented a hi-hat choke that muted the open hat whenever the closed hat note was received. That interaction is not modelled here — each note decays independently.

## Section labels in the Knobs panel

A circuit with 13 parameters spread across nine instruments is difficult to navigate as a flat list. The `val:section` property on `val:Param` bindings groups parameters under named headings in the Knobs panel:

```turtle
:pBdDecay a val:Param ; val:slot 1 ;
    val:target :bdAmpEnv ; val:property val:decay ;
    lv2:name "Decay" ; lv2:symbol "bd_decay" ; val:section "Bass Drum" ;
    units:unit units:ms ; lv2:minimum 10.0 ; lv2:maximum 2000.0 .
```

The Knobs panel renders a coloured label and a divider line at the start of each new section. Bindings without a `val:section` are displayed ungrouped.

## Known simplifications

- The hi-hat uses two oscillators instead of the original six. Adding more oscillators is straightforward.
- Hi-hat choke (open hat silenced by closed hat) is not implemented. A UnitDelay feedback path or a separate mute control arc would be needed.
- Velocity is applied through the global `args.velocity` inside the Envelope, which reflects the most recently triggered note, not the specific note that triggered each instrument. In practice this works for sequential playing but not for simultaneous hits at different velocities.
- Toms do not have pitch sweep envelopes, which the original 909 does include.

## Testing with MCP tools

To load and play the circuit using the Transmission host:

```
mcp__transmission__project_open(path: ".../examples/909.ttl")
mcp__transmission__transport_play()
```

Send MIDI note 36 (bass drum), 38 (snare), 42 (closed hat) on channel 10. Each instrument should respond independently; others should remain silent during each note.

Inspect the compiled circuit graph to verify NoteGate appears in each instrument chain and that control arcs connect to Envelope gate ports:

```
mcp__transmission__project_get()
```
